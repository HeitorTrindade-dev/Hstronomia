# Hstronomia Frontend

SPA desenvolvida com React 18, Vite, TypeScript e Tailwind CSS.

## Instalação e Execução

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Execute o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Build de produção:
   ```bash
   npm run build
   ```
